The answer in one slide

Four questions, four answers

1 · Is Azure what UAE companies use?

Microsoft is deeply embedded in the UAE: two Azure regions (Dubai, Abu Dhabi), a $1.5 bn stake in G42, and the Abu Dhabi government's sovereign cloud built with Microsoft and Core42. AWS has one UAE region; Oracle has two; Google has none. [believed]

We found no market-share figure that supports "most companies" — Azure is a common, well-supported choice, not a proven majority.

2 · Can the AI stay in the UAE on Azure or AWS too?

Only partly. Azure's pay-per-use AI ("Global Standard") runs outside the UAE; its in-country option is reserved capacity from about $6,500 a month. AWS sells a few models in-region, but its UAE region is impaired. Core42 runs our exact model in the UAE for about $7 a month. [believed]

3 · What does it cost per month?

About $202 on Azure UAE North with Core42 — one server running today's software unchanged, nightly backups copied to Abu Dhabi, AI and voice included. About $282 with a managed database. estimate Hostinger was $57 — but abroad.

4 · Where does Copilot fit?

GitHub Copilot to build and update the code: yes — $19 per developer a month. Its processing is in the US/EU, so no real employee data ever goes into it. Microsoft 365 Copilot is for office work, not this system; Copilot Studio would duplicate what we already built. [believed]

What 2026 changed

"In the UAE" is now a resilience question, not only a legal one

1 March 2026 — AWS's UAE data centres were struck

Drone strikes during the Iran conflict damaged AWS facilities in the UAE (me-central-1) and Bahrain. At the peak more than 100 AWS services in the UAE region were disrupted; banks, Careem and payment firms reported outages. [believed — CNBC, The Register, InfoQ]

AWS health dashboard, 15 September 2026 (as reported): it is "unable to restore access to the resources and data hosted exclusively in the mec1-az2 availability zone" — and it recommends customers in the Middle East "backup data and potentially migrate your workloads to alternate AWS Regions."

AWS waived March charges and says it is replacing the infrastructure, with "service restoration in the coming months". [believed — InfoQ, Computing, The Stack]

Azure has not been hit — but is not out of scope

No strike on Microsoft's UAE data centres was reported. On 31 March Iran's IRGC named Microsoft, Google, Oracle and others as "legitimate targets"; Microsoft said it is rethinking data-centre design for war zones. The UAE is reported to be considering dispersed and underground data centres. [believed — The Register, Cybernews, press]

What it means for us
  • A backup in the same building is not a backup. AWS customers who kept data in one zone lost it.
  • Keep the second copy in a different emirate. Azure copies storage from Dubai to its paired Abu Dhabi region automatically ("geo-redundant"); AWS has only one UAE region.
  • Be able to rebuild in hours. Our system is one Docker Compose stack plus a database dump — that is already true, and we will rehearse it.
  • An encrypted copy outside the UAE is the last line of defence — a decision for counsel under PDPL Art. 23, not a default.

How it can be deployed

Three ways to run our system on a hyperscaler

A · RECOMMENDED START

One server, today's software

One virtual machine in Dubai runs the Docker Compose stack exactly as tested. Nightly database dump to storage that Azure copies to Abu Dhabi.

  • Code changes: none
  • Move time: days
  • Weak spot: the server is a single point of failure — restore from the Abu Dhabi copy
B · WHEN IT MATTERS MORE

Managed database

The app stays on a smaller VM; PostgreSQL moves to Azure's managed service (patching, point-in-time restore, optional zone-redundant standby).

  • Code changes: a connection string, plus re-checking our row-level-security roles on the managed service
  • Move time: a week
  • Cost: ~$80 a month more
C · LATER, IF EVER

Fully managed containers

Each service on Azure Container Apps (or AWS ECS). Scales to zero, no server to patch — but more moving parts than 40 people need.

  • Code changes: small (build images, secrets)
  • When: Phase 4 telemetry, or 200+ users
  • Not priced — not needed

Why "not now"

  • AWS says data held only in one UAE zone cannot be restored, two other zones are still being recovered, and it advises Middle East customers to back up and consider moving to other AWS regions — i.e. out of the country.
  • AWS has one UAE region, so there is no in-country second region to copy backups to.
  • A price list is not capacity: the prices are published, but we have not confirmed that new servers can be launched in the healthy zone.
When to revisit: once AWS declares me-central-1 fully recovered. The system would move in days — the same Docker Compose stack runs on EC2 unchanged (ARM included, [believed — not tested on ARM]).

Building and updating with Copilot

How Copilot is used safely on this codebase

What it is good for here

  • Routine code — new API routes, dashboard screens, tests — against the specs already in the repository.
  • Reviews on every pull request, alongside the human one.
  • The coding agent for small, well-specified tasks: it opens a pull request that CI must pass and a person must approve.
  • Explaining the code to a new developer — the repository's own documents give it the context.

The rules — because its processing is outside the UAE

  • No real employee data in any prompt, file or test — synthetic data only, as the repository already does (is_synthetic).
  • No secrets: .env is excluded from git (done 26 Sep) and should be excluded from Copilot's context too (content exclusion setting). [believed]
  • Business plan, not personal accounts — the company controls policy, and code is not used for training on business plans. [believed]
  • Copilot suggests; the pipeline decides. Every change still passes typecheck, the full test suite and review. Deterministic routing and escalation are never replaced by a model.
Source code is not personal data. Sending code to a US or EU processing region is a business and security decision, not a PDPL transfer — as long as the rules above hold. The moment a real name, phone number or status note reaches a prompt, it becomes one. [believed — counsel to confirm]

Targets we can commit to

  • Lose at most one day of data if the Dubai site is destroyed (nightly dump; hourly is a small change).
  • Back up within about four hours on a new server in Abu Dhabi or elsewhere — the software is one Compose file. estimate — to be rehearsed
  • A restore test every month, recorded — a backup that has never been restored is a hope, not a backup.
Telegram and the app during an outage: if our server is down, Telegram still delivers messages already sent, and people can report again once it is back; nothing is lost that was already written to the database. The app channel depends on our server, so it goes down with it — one more reason to keep Telegram as the default for field staff.

  • The 4 vCPU / 16 GB size is a judgement, not a load test. The 8 / 32 like-for-like is priced alongside for that reason.
  • The four-hour recovery target has not been rehearsed.
  • Core42's Qualcomm price ($0.15 / $0.37) was read on their page on 21 Sep and could not be re-confirmed today; the Cerebras price could. Core42's API has not been tested with our prompts, and its DPA has not been seen.
  • Nova, GPT-5.x and any Azure model are untested on our multilingual extraction.
  • Copilot prices and residency are from search results (usage-based billing changed on 1 Jun 2026). Whether Copilot's content-exclusion setting covers every surface we use has not been checked.
  • "Source code is not personal data" is our reading, not counsel's.
  • Market share: we found no reliable figure for how many UAE companies use Azure versus AWS.
