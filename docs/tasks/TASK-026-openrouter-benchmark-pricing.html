2 · Research

  • OpenRouter pricing (web, 2026-09-12): no per-token markup — provider prices pass through — and a 5.5% fee on buying credits, minimum $0.80. The report adds that fee to every OpenRouter row.

7 · The cost log records real money (D66)

All 296 model calls logged before today said cost_usd = 0: the price table was empty, so the daily budget cap could never trip. Now the client records OpenRouter's own usage.cost when it is sent, and otherwise tokens × list price from cost.ts. Three new tests cover the billed path, the estimated path and the price table.

8 · FastAPI — what to say

"We evaluated FastAPI and kept the current TypeScript backend. It already does everything FastAPI would give us, the whole system is one language, and a rewrite would cost weeks without changing anything a user sees. We will add Python where it earns its place — forecasting and route optimisation — as a separate service, not a rewrite."

The three reasons behind it, and what would change the answer, are in a card in docs/reports/architecture-recommendation.html, section 03 (D68).

9 · A test that failed at midnight (G68)

The first full run failed 7 end-of-day tests at 00:35 Dubai. The test took "today" as the UTC date; the code correctly uses the company day. Between midnight and 4 a.m. they disagree. The test now uses companyToday(); nothing in production was wrong.

What we have not verified

  • Correctness is one sample per task. gemini-2.5-flash-lite's 5/5 needs a repeat before it replaces gpt-4o-mini (D67); G51 showed a single sample can mislead in either direction.
  • Why paid OpenRouter calls work with no purchased credit — and how long they will (G66).
  • The monthly figures rest on assumed volumes (staff count, three updates each a day, EOD and question sizes). Replace them with real counts once the bot has run for a few weeks.
  • Latency is from one machine, in one hour, on one Wi-Fi. Another time of day, or a server in a data centre, will differ.
  • NVIDIA and local models were not in the repeat pass — NIM calls take 12–100 s, and the Ollama container was not running. Their single-sample numbers from TASK-024 stand.
  • Pinning an OpenRouter upstream (provider.order) was recommended for open-weight models but not tried.
  • The budget cap with real costs has only been exercised by the synthetic test; at the measured rates it is far above a day's spend.

Security

  • The new OpenRouter key was pasted into chat, like the ones before it. Rotate every key — Groq, both OpenRouter keys, the NVIDIA keys, the bot token — before this runs anywhere but this laptop.
  • CREDENTIALS.local.md holds two passwords in plain text. It is git-ignored and local, which is what you asked for; it is not a password manager, and the passwords should change before a wider demo.
  • The benchmark sent only synthetic prompts. In production the fallback's upstream (OpenAI or Azure, for gpt-4o-mini) would receive real employee messages — that belongs in the PDPL notice as a named processor.
