One-sentence summary: The compliance rules the CEO deck designed are now in the system: one file says where personal data may go and on what ground, the api, worker and bot check themselves against it at every start (reported in the demo, refusing to start in production), every AI prompt loses its phone numbers, emails, Emirates IDs, IBANs and card numbers before it leaves, the CEO has a Compliance page with the evidence and a daily snapshot in the audit log, and everyone can download a copy of their own data.

Research (30 Sep)

  • OpenRouter's routing fields are provider: { data_collection: "deny", zdr: true } — its provider-routing documentation, through search [believed; not exercised against OpenRouter from here].
  • Emirates ID: 15 digits, 784-YYYY-NNNNNNN-C — several guides agree [believed].
  • PDPL data-subject rights: information (Art. 13), a machine-readable copy (Art. 14), correction and erasure (Art. 15) — search summaries [believed; article numbers to confirm on the law's text].
  • A Cloudflare quick tunnel terminates TLS at Cloudflare's edge, which can therefore read the traffic, sign-in included; quick tunnels are for testing [believed — Cloudflare's docs and two write-ups, through search]. This changed the demo guide.
  • Langfuse offers a DPA and stores its EU cloud in Ireland [believed].
  • No YAML parser is in the project, so the registry is JSON (Zod-validated) rather than add a dependency (CLAUDE.md).

What was built

RuleWhat it checksWhere
R0The registry exists and matches its schemaAt start-up of the api, worker and bot (checkPolicyAtStartup); on the Compliance page; pnpm compliance [--production]. Demo: one summary line, nothing blocked. IS_DEMO=false: every finding printed and the process exits.
R1Every service the configuration can reach (the same tests the senders and the AI client use) is registered
R2A legal ground; "contract" needs a filed DPA with a date; a processor offering none is refused
R3The host is in an allowed country and is not a laptop
R4AI providers keep nothing — confirmed, with a date; OpenRouter also data_collection: "deny"
R5The consent notice names every service receiving personal data (and a host abroad)
R6Retention set, sign-in on, no quick tunnel, no prompt copies to tracing; a page reached through Cloudflare says so
R7Identifiers removed from every AI prompt; count per call in llm_call.redactedThe AI wrapper, once per call, before any provider or trace sees it
R8Evidence: consent by version, AI calls and removals, messages per channel, retention, erasures, exports, withdrawalsCEO's Compliance page; a daily snapshot in the append-only audit log (worker)
  • Download my data (Alerts → Your consent) and Export (People, CEO only): a JSON file of one person's profile, consent, tasks, own words, problems, assignments, progress, inbox, devices (push keys left out — they are secrets), reports and actions; bounded to 5 000 entries per section; audited as data.exported. The self-export is on the consent-free list: a person's data is theirs whatever notice they agreed to.
  • Names are not removed from prompts — the document planner routes by name and the parser needs to know who is affected. A decision, not a gap.
  • The notice did not change, so nobody is asked to agree again; the demo on the laptop starts exactly as before, with one extra log line per service.

What we have not verified

  • Through a real Cloudflare tunnel: detection uses the Host header or Cloudflare's cf-ray header; tested by sending those headers, not by a request through cloudflared.
  • OpenRouter's zero-retention fields against a live call — the shipped registry leaves them off, so the demo sends exactly what it did before.
  • How redaction changes the AI's reading of real updates — no live model in this environment. A parse that needed a phone number now sees "[phone]".
  • Bare 10-digit Indian mobiles without +91 are not removed (they look like order numbers); names are never removed.
  • Encrypted backups, database exposure, server hardening — not visible from configuration, so no rule checks them.
  • The legal readings (grounds, Art. 13–14 numbering) — no lawyer has reviewed them.
  • A real phone saving the download (Android Downloads, iPhone Files) — tested in desktop Chromium only.
